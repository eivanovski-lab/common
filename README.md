## Меню и каталог книг

- `catalog.js` — единый список квизов. На нём строятся главная страница и меню «Книги» на каждой странице квиза (с прогрессом «знает / повторить» из localStorage).
- `nav.js` — меню «Книги». На странице квиза подключается перед `data.js`: `<script src="../catalog.js"></script><script src="../nav.js"></script>`.
- Новая книга: положить квиз в папку `slug/`, добавить строку в `catalog.js` (`status:'ready'`, `key` — ключ отметок из `index.html` квиза). Пока квиз готовится — `status:'soon'`, он виден в меню без ссылки.

## Синхронизация отметок между устройствами

- `sync.js` — хранит отметки всех книг в файле `marks.json` приватного репозитория `eivanovski-lab/quiz-marks` (GitHub Contents API, без своего сервера). Слияние по каждому вопросу: побеждает более позднее изменение.
- Подключение устройства — меню «Книги» → «Синхронизация»: вставить ключ (fine-grained token только на `quiz-marks`, Contents: Read and write) или открыть ссылку `…/common/#sync=<ключ>` с уже подключённого устройства. Ключ хранится только в localStorage устройства.
- Страница квиза подключает `../sync.js` в самом конце и задаёт `window.QUIZ_KEY` и `window.QUIZ_APPLY` (см. любой квиз).
