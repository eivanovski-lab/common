# common

Общие материалы для шеринга. Каждый материал лежит в своей папке и публикуется через GitHub Pages: https://eivanovski-lab.github.io/common/

| Папка | Что это | Ссылка |
|---|---|---|
| `vera-anfisa/` | 200 вопросов по книге Э. Успенского «Про Веру и Анфису» с полным текстом и отметками «знает / повторить» | https://eivanovski-lab.github.io/common/vera-anfisa/ |
| `alya/` | 184 вопроса по повести И. Токмаковой «Аля, Кляксич и буква „А“» с полным текстом и отметками «знает / повторить» | https://eivanovski-lab.github.io/common/alya/ |
| `udivitelnyj-den/` | 150 вопросов по рассказу В. Драгунского «Удивительный день» («Денискины рассказы») с полным текстом и отметками «знает / повторить» | https://eivanovski-lab.github.io/common/udivitelnyj-den/ |
| `tsvetik/` | 177 вопросов по сказке В. Катаева «Цветик-семицветик» (9 частей по лепесткам) с полным текстом и отметками «знает / повторить» | https://eivanovski-lab.github.io/common/tsvetik/ |

## Меню и каталог книг

- `catalog.js` — единый список квизов. На нём строятся главная страница и меню «Книги» на каждой странице квиза (с прогрессом «знает / повторить» из localStorage).
- `nav.js` — меню «Книги». На странице квиза подключается перед `data.js`: `<script src="../catalog.js"></script><script src="../nav.js"></script>`.
- Новая книга: положить квиз в папку `slug/`, добавить строку в `catalog.js` (`status:'ready'`, `key` — ключ отметок из `index.html` квиза). Пока квиз готовится — `status:'soon'`, он виден в меню без ссылки.
